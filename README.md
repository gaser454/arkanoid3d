# Арканоид (3D)

Многоязычная реализация классической игры «Арканоид» с эффектом 3D-перспективы в консоли.  
Игрок управляет платформой, отбивает мяч и разрушает блоки. 3D-эффект достигается за счёт псевдопроекции: блоки отображаются с учётом глубины, а мяч и платформа имеют объёмные символы.

## Особенности
- Псевдо-3D перспектива в консоли: блоки на разных «уровнях» глубины имеют разный размер и яркость.
- Управление платформой с помощью клавиш `A`/`D` или стрелок `←`/`→`.
- Мяч с реалистичной физикой: отскок от стен, платформы и блоков.
- Разрушаемые блоки с разной «прочностью» (цветовая индикация).
- Бонусы (power‑ups): расширение платформы, замедление мяча, многомячье.
- Подсчёт очков и сохранение рекордов.
- Уровни сложности: при уничтожении всех блоков игра переходит на следующий уровень.
- Цветной вывод в терминале (где поддерживается).

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости.

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama`  
   Запуск: `python arkanoid3d.py`

2. **JavaScript (Node.js)**  
   Установка: `npm install chalk readline`  
   Запуск: `node arkanoid3d.js`

3. **Go**  
   Запуск: `go run arkanoid3d.go`

4. **Rust**  
   Сборка: `cargo build --release`  
   Запуск: `cargo run --release`

5. **Java**  
   Сборка: `javac Arkanoid3D.java`  
   Запуск: `java Arkanoid3D`

6. **C# (.NET Core)**  
   Запуск: `dotnet run`

7. **C++ (Linux)**  
   Сборка: `g++ -std=c++11 -o arkanoid3d arkanoid3d.cpp -lpthread`  
   Запуск: `./arkanoid3d`

8. **Kotlin (JVM)**  
   Сборка: `kotlinc Arkanoid3D.kt -include-runtime -d arkanoid3d.jar`  
   Запуск: `java -jar arkanoid3d.jar`

## Управление
- `A` / `←` – движение платформы влево
- `D` / `→` – движение платформы вправо
- `Q` – выход из игры
- `R` – перезапуск после окончания игры
